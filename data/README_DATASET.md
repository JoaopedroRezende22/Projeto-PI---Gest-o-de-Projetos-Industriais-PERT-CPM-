# Dataset

`projeto_exemplo.txt` é um dataset pequeno e controlado para validação funcional dos algoritmos.

Ele **não** substitui o requisito do trabalho de utilizar uma base real com pelo menos 1.000 vértices.

Quando a base real for escolhida, manter o arquivo original e registrar em documentação:

- fonte;
- URL da fonte;
- data de acesso;
- significado dos vértices;
- significado das arestas;
- quantidade de vértices;
- quantidade de arestas;
- tratamento de dados ausentes ou duplicados;
- tamanho dos subconjuntos usados nos experimentos.
